今朝のブリーフィング

火曜の朝、各社の新モデルが一斉に顔を出した。OpenAIはGPT-6.2 AstraとSolを出し、Astraは自己改善で「High」の閾値に達した初の外部公開モデルだという。Microsoftは自社のMAIモデルを7種そろえ、Code 2はGPT-6.1 Solの約98%の品質を約4割の価格で狙う。GoogleはGeminiの「Tasks」を広げ、チャットが電話や購入まで引き受け始めた。

一方で、AIを手元へ引き寄せる動きもある。3210億パラメータのGLM-5.3-FlashをGPU1枚で動かすProject Mayaや、データの扱いを売りにするProtonのLumoデスクトップだ。ある開発者は就寝前に一度指示を出し、朝には完成したゲームを手にした。答えるAIから任せるAIへ。目覚めた朝の驚きは、やがて日常になるのだろう。

01

OpenAI「GPT-6.2」登場　Astraは自己改善で初の「High」判定

専門業務向けのAstraと日常向けのSolの2種で、Plus以上のChatGPTとAPIで利用可能。AstraのAPI価格は前世代より20%安いが、難しい事実質問での幻覚率は59%と指摘されている。

「According to OpenAI, GPT-6.2 Astra is the first externally released model to reach the "High" threshold for AI self-improvement.」— THE DECODER

THE DECODER（11/17）

02

Microsoftが自社AI「MAI」7種を一挙公開　コード用は価格4割で品質98%

Ignite 2026で、コーディング、画像、音声、セキュリティなどのモデル群を発表。MAI Code 2はGitHub Copilotで使え、GPT-6.1 Solの約98%の品質を約40%の価格で提供するとしている。

「Dragon Copilot Transcribe, built on MAI Transcribe 2, already handles 10 million patient encounters a month.」— TestingCatalog

TestingCatalog（11/17）

03

Microsoft、Copilotに「分身」エージェント　PCを閉じても働き続ける

個人向けエージェント「Autopilot」がTeamsとOutlookで提供開始。独自の記憶とクラウド上のPCを持ち、メールの送信や日程調整、定期タスクをこなす。返信の下書きは承認するまで保留される。Frontierプログラムのプレビュー。

TestingCatalog（11/17）

04

GeminiのTasks、無料で拡大　電話予約や購入までAIが代行

チャットからTasksに切り替えると、Geminiが店への電話や予約、Google Payでの購入を代行する。新モデルGemini 4 Hydrogenで動き、多くのユーザーに無料で広がる。

「Google is expanding the rollout of Tasks, a toggle in Gemini that converts the chatbot into a more active helper.」— TechCrunch

TechCrunch（11/17）

05

Proton「Lumo」にデスクトップ版　ローカルファイルも扱う民間AIエージェント

Windows・macOS・Linux向け。ファイル操作やシェル実行、MCPサーバーに対応し、コネクタごとに自動実行・要承認・禁止を設定できる。会話履歴は暗号化され、AI学習には使わないとしている。

「The app is designed to offer users more control over their personal data,」— TechCrunch

TechCrunch（11/17）

06

3210億パラメータのGLM-5.3-Flashが1枚のGPUで動く「Project Maya」

MoEの専門家をVRAM・RAM・SSDで入れ替えながら動かすオープンソースツール。RTX 3090 1枚で毎秒26トークンの報告がある。ただし推奨メモリは88GB以上で、VRAM 8GB・RAM 64GB環境ではエラーになった。

「Project Maya is a free, open-source tool that allows you to run massive models even in a single-GPU environment」— GIGAZINE

GIGAZINE（11/17）

07

寝る前に一度頼んだら朝にゲーム完成　Claude Fable 5.2の実力

Canva勤務の開発者が、甥の誕生日用に詳細な指示を1回出して就寝。Claude Fable 5.2は既存コードを大半作り直し、全12ステージを自動で遊んで検証するボットまで作った。素材にはOpenAIの画像生成とElevenLabsを使用。

「When I woke up in the morning, the game was finished.」— GIGAZINE

GIGAZINE（11/17）
