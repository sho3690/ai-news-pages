今朝のブリーフィング

AIが画面の中から、生活の動線へと染み出している。Claudeの成果物であるArtifactsはMacやWindowsに単体のアプリとして入れられるようになり、MetaのMuseはInstagramのDMに住みはじめた。Muse はさらにApple Messagesへ向かう気配がある。OpenAIもChatGPTのDotsに専用のメールアドレスを持たせる準備をしているようだ。AIは「開いて使う道具」から、受信箱や通知のそばに控える存在へ変わりつつある。

だが、居場所が増えても腕前が追いつくとは限らない。日常の用事を集めた新しい物差しでは、有力モデルでも三分の一以上で失敗した。一方、翻訳に特化したTencentのHy MT3や、5.9GBまで軽くしたBonsaiのように、手元で動く小さなモデルも着実に育っている。置き場所の広さより、任せて大丈夫かどうか。その見極めが次の勝負どころだろう。

01

ClaudeのArtifacts、MacとWindowsの単体アプリに

AnthropicがArtifactsをMac・Windowsのアプリとしてインストールできるようにした（ベータ版）。メニューバーや通知、コネクタ、Claude自体も使える。

「Anthropic now lets you install Claude Artifacts as Mac or Windows apps.」— THE DECODER

THE DECODER（11/24）

02

MCPのSDK、月7億DL突破　長時間タスクや確認質問にも対応

Anthropicによると、MCPは月間SDKダウンロードが7億超、コネクタは1万超に。長い作業を預けるTasks、不足情報を尋ねるElicitation、Skills over MCPが加わった。

「Elicitation lets a running process pause and ask the user for specific missing details.」— THE DECODER

THE DECODER（11/24）

03

MetaのMuse、Instagramの DMに登場　保存した投稿の整理も

Museのアプリに切り替えなくても、InstagramのDMで直接やり取りできるように。保存した投稿やリールをMuseに整理させることもできる。

「Meta says that users remain in control of their Muse experience on Instagram.」— TechCrunch

TechCrunch（11/24）

04

Muse、次はApple Messagesへ？　設定に隠れた項目を発見

Museの設定に「Apple Messages for Business」へ続く項目が見つかった。一般ユーザー向けか事業者向けかは不明で、提供時期も未確認。

「The option is not yet available to users.」— TestingCatalog

TestingCatalog（11/24）

05

ChatGPTのDots、専用メールアドレスを持つ日が来る？

OpenAIが、常時稼働エージェントDotsごとに専用のメールアドレスを持たせる機能を準備している。現時点では画面内に隠れており、使えない。

「The feature is still hidden in the interface and is not available to users yet.」— TestingCatalog

TestingCatalog（11/24）

06

有力AIエージェント、日常の用事で3割超が失敗　新ベンチ「ShellBench」

OpenAI、Anthropic、Metaの上位モデルが、日常タスクの3分の1以上で失敗。試行の15.7%は安全要件にも違反した。GPT-6 Astraは同じ課題の3回全成功が半数未満だった。

「It seems many of today's AI agents are still not up to the task.」— TechCrunch

TechCrunch（11/24）

07

Tencent「Hy MT3」登場　102言語対応の翻訳特化モデル、手元でも動く

30B・7B・1.8Bの3サイズで日本語を含む102言語に対応。Hugging FaceにFP8やGGUF版もあり、最小版でも商用翻訳サービスを上回ると主張する。

「The license used is the Apache License 2.0.」— GIGAZINE

GIGAZINE（11/25）

08

メモリ5.9GBに圧縮「Ternary Bonsai 2.5 27B」　エージェント性能は維持

PrismMLがQwen3.8 27Bをもとに、重みを3値に絞った公開モデルを発表。メモリ使用量を5.9GBに抑えつつ、前版よりエージェント系の指標を改善した。

「It is licensed under the Apache License 2.0.」— GIGAZINE

GIGAZINE（11/25）
