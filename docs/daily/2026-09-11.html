今朝のブリーフィング

DeepSeekが新型「V4.1 Flash」を投入し、価格を下げながらGPT-5.6やClaude Opus 5を上回る数値を示した一方、OpenAIはGPT-6 Astraの安全性を高め、誤った出力を大幅に減らしつつ、企業が操作範囲を制御できる新機能や音声応答の強化もあわせて発表した。

開発の現場でも足場固めが進む。GitHub Copilotはコードの品質問題をまとめて自動修正できるようになり、GoogleはAIエージェント開発キットをKotlinにも広げた。一方でNTT西日本は、AIで昔ばなしの名ナレーターの声を6カ国語によみがえらせている。効率化と保存、生成AIは両方の役割を静かに広げている。

01

DeepSeekが新型「V4.1 Flash」公開、値下げも

中国DeepSeekが新モデル「DeepSeek-V4.1-Flash」を発表した。総パラメータ5520億のMoE構成で旧モデル「V4 Pro」を性能・速度・コストの全てで上回り、GPT-5.6 SolやClaude Opus 5に匹敵する結果も示しつつ、API価格は引き下げられた。

「より賢く、より速く、より効率的」— ITmedia

ITmedia（9/10）

02

GPT-6 Astra、サイバー能力が「最高レベル」到達

OpenAIが、GPT-6 Astraのサイバーセキュリティ関連能力が自社の安全基準「Preparedness Framework」上で最高区分の「Critical」に達したと発表した。追加の安全学習で意図しない出力を大幅に減らしたほか、Web利用や重要操作を管理者が制御できる企業向け新機能も加えた。

AI Watch（9/10）

03

ChatGPT音声にGPT-6 Astra対応、利用枠拡大

OpenAIがChatGPTの音声モードを刷新し、難しい調べ物や推論が必要な場面ではGPT-5.6やGPT-6 Astraを呼び出せるようにした。あわせて音声対話「GPT-Live」の利用可能時間もプランごとに拡大された。

「Do not assume GPT-5.6 or Astra answers every Voice turn; treat them as possible escalation paths for harder work.」— ChatGPT AI Hub

ChatGPT AI Hub（9/10）

04

Adobe Acrobat、PDFを要約ポッドキャストに変換

Adobeが日本語版Acrobatに、チャットでPDFを編集できる機能と、文書の内容を音声で要約する「ポッドキャスト生成」機能を追加した。ページ削除や署名追加、パスワード設定なども自然な言葉で指示できる。

「生成された音声は、ドキュメント内の主要な情報を整理し、わかりやすく説明するため」— AI Watch

AI Watch（9/10）

05

GitHub Copilot、コード品質問題を一括自動修正

GitHubが、コード品質の指摘事項を最大25件までまとめてCopilotに割り当て、自動で修正・検証し、プルリクエストの作成まで任せられる「Agentic Autofix」機能を追加した。

「Copilot starts fixing them agentically on a branch, validates its own changes, then opens a pull request for you to review and merge.」— GitHub Blog

GitHub Blog（9/9）

06

Google、Kotlin用AIエージェント開発キット正式版

Googleが、Kotlin向けAIエージェント開発キット「ADK for Kotlin」の正式版（1.0）を公開した。Python版・Java版と機能面で完全に足並みをそろえ、スマホ上で動くオンデバイスAIエージェントも構築しやすくなった。

「ADK for Kotlin 1.0 delivers complete alignment with ADK Python and Java, bringing advanced multi-agent coordination patterns to idiomatic Kotlin.」— Google Developers Blog

Google Developers Blog（9/9）

07

NTT西日本、AIで名ナレーターの声を6カ国語に復元

NTT西日本が、AIで「まんが日本昔ばなし」の名ナレーター2人の声を復元し、6カ国語で発話できるようにした。9月18日から麻布台ヒルズで、多言語デジタルサイネージとして披露される。

ASCII.jp（9/9）
