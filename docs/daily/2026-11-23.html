今朝のブリーフィング

AIが「待つ」から「見張る」へ、そして「手元で動く」へ。そんな変化が今朝の紙面に並ぶ。Perplexityは、ウェブを定期的に巡回して変化だけを知らせるMonitor APIを公開した。GoogleはAntigravityに、返事待ちのエージェントを一覧する受信箱を用意しているという。xAIのGrok Botも、自分のパソコンを直接操る機能が準備中だ。机の上の仕事に、静かな同僚が増えていく。

ただ、働きぶりを測る物差しは厳しい。模擬の職場で試すと、最新モデルでも課題を完走できるのは一割に満たなかった。GPT-6.2は答えが簡潔になった反面、疑いを口にする場面は減ったという。賢さの競争は、話し方や持久力の吟味へ移りつつある。頼もしさとは、速さだけではないのだろう。

01

Perplexity、ウェブを「見張る」Monitor APIを公開

定期的にウェブ検索やページ確認を行い、開発者が決めた目的に合う新しい変化だけをアプリやエージェントへ通知する。判定モデルが各結果を評価し、社内テストではFirecrawlやExaを上回ったという。

「Perplexity's new Monitor API watches the web on a schedule and sends updates to apps and agents via webhook.」— THE DECODER

THE DECODER（11/22）

02

GPT-6.2は「端的」だが、疑いは口にしない？　Claudeと比較

Artificial Analysisの評価で、GPT-6.2 AstraとSolは見出しが少なく回答が簡潔になった一方、不確かさを認める頻度が低かった。構造や透明性ではClaude Fable 5.2やOpus 5.5を下回るが、測るのは文体であり正確さではない。

「The personality scores describe differences in communication style, not overall answer quality.」— THE DECODER

THE DECODER（11/22）

03

最新モデルでも「職場の課題」完走は1割未満　模擬会社で検証

同僚やタスクボード、メッセージ履歴のある模擬ソフト会社でコーディングエージェントを働かせる実験。Claude Opus 5.5やGPT-6 Astraでも、割り当てられた課題を完全に終えられたのは10%未満だった。

「Success stories about AI coding agents keep piling up.」— THE DECODER

THE DECODER（11/22）

04

GeminiのサブスクがHermes Agentでも？　12月2日に変化の気配

GoogleのLogan Kilpatrick氏が、Geminiの契約が第三者のエージェントツールでも使えるようになる可能性を示唆。Nous ResearchのHermes Agentが有力な対象とされるが、両社とも確認していない。

「Neither Google nor Nous has named Hermes, so its place in the first wave remains likely rather than confirmed.」— TestingCatalog

TestingCatalog（11/22）

05

Grok Bot、自分のMacを直接操る「ローカル操作」を準備中

Mac版Grok Botに、現在のクラウド上のマシンだけでなく利用者のデスクトップ上のアプリを操作するComputer Useが準備されている。どのアプリでも使える音声入力も開発中だが、まだ提供されていない。

「SpaceXSI has not shared any release timing.」— TestingCatalog

TestingCatalog（11/23）

06

AntigravityにAIの「受信箱」　返事待ちのエージェントを一覧

GoogleのコーディングアプリAntigravityで、ユーザーの入力を待つエージェントのスレッドを「Inbox」と「Resolved」に分けて表示するモードを開発中。説明文から独自エージェントを作る機能も計画されているという。

「The feature is still in development and isn't available yet.」— TestingCatalog

TestingCatalog（11/23）

07

Geminiアプリのカメラが刷新　下から引き上げる新UI

Android版Geminiアプリのカメラが、全画面ビューファインダーから、ドラッグで画面の大半まで広げられるボトムシートに変わった。先にiOSで登場した仕様で、ベータ版と安定版に順次展開される。

「The new one appears inline on the Gemini homepage or inside a conversation.」— 9to5Google

9to5Google（11/21）

08

「テキストで話しかける」AIエージェント特集　iMessageでも使える

別アプリを入れず、テキストメッセージやiMessageで頼めるAIアシスタントを一覧で紹介。万能型の秘書から家族・旅行・仕事向けまで幅広く、Instinctが注目株として挙げられている。

「Rather than downloading another app, a growing number of agents can simply be texted like an ordinary person.」— TechCrunch
