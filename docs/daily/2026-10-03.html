道具が使い手に合わせて形を変える日だった。Claude Codeには、TypeScriptの小さなモジュールで振る舞いも画面も書き換えられる「Mod」が加わった。一方のPiは、読む・実行する・直す・書くの4機能を核に、小さな道具のまま1.0に達した。大きく育てるか、小さく磨くか。開発の現場には二つの流儀が並び立つ。

画像や声の側でも、細部への注文が通るようになってきた。FLUX 3 Imageは枠で位置を指定でき、ほかの画素に触れずに直せるという。MicrosoftはリアルタイムのMAI-Transcribe-2-Streamingを出し、Tavusの映像モデルは1分の通話で約半数に本物の人間と思わせた。生成物が「それらしい」から「注文どおり」へ移るなか、注文を出す側の腕も問われそうだ。

01

Claude Codeが「改造」可能に、TypeScriptのModで挙動もUIも変更

Claude CodeにTypeScriptで書けるMod機能が加わった。挙動やUIを変えたり独自機能を差し込んだりでき、Claude自身にModを作らせることもできる。プラグインとして配布でき、CLIとデスクトップアプリの両方で使える。

「Change how it behaves - Customize the UI - Swap in your own features」— GIGAZINE

GIGAZINE（10/2）

02

画像生成「FLUX 3 Image」登場、最大4K＆位置指定＆部分編集

Black Forest Labsが画像生成AI「FLUX 3 Image」を公開した。最大4K出力、枠による被写体の位置指定、最大10枚の参照画像、日本語テキスト生成に対応し、オープンモデル版も数週間以内に出る予定だ。

「Make precise multi-turn edits without changing any other pixel.」— GIGAZINE

GIGAZINE（10/2）

03

無料のAIコーディングツール「Pi 1.0」、小さな道具のまま正式版へ

無料＆オープンソースのPiが正式版1.0に到達した。MCPへの標準対応や複数モデルの切り替え、ツール読み込みの最適化が加わり、「小さなハーネス」という持ち味は保たれている。

「Piは大量の機能を最初から搭載する方向を避け、ファイルを読む「read」、コマンドを実行する「bash」、ファイルを修正する「edit」、ファイルを作成する「write」という4種類の機能を基本としてきました。」— GIGAZINE

GIGAZINE（10/2）

04

Microsoft、初のリアルタイム文字起こしAIを投入

Microsoftが同社初のリアルタイム文字起こしモデル「MAI-Transcribe-2-Streaming」をリリースした。第三者の分析では誤り率と遅延で競合を上回り、APIは2026年末まで1時間あたり0.54ドルで使える。

「MAI-Transcribe-2-Streamingはテスト対象のリアルタイム文字起こしモデルの中で最もエラー率が低いです。」— GIGAZINE

GIGAZINE（10/2）

05

「本物の人」と思った人は48％、Tavusが対面会話AI「Griffin」

Tavusが、音声と映像を連続的に処理して会話するビデオ対ビデオのモデル「Griffin」を発表した。1分の通話で参加者の48％が本物の人間だと信じたという。現在は一部のテスター向けの提供で、広い公開は安全対策が整ってからになる。

「Perception, conversational decision-making, and generation run concurrently throughout the conversation, so the model can respond to changes while it is speaking as well as while it is listening.」— Tavus

Tavus（10/1）

06

KDDI傘下ELYZA、国産LLM-jp-4ベースの推論モデルを無料公開

ELYZAが国産基盤モデル「LLM-jp-4」をもとにした2つのモデルをHugging Faceで公開した。Apache 2.0ライセンスで商用利用ができ、20指標の比較では国立情報学研究所の「LLM-jp-4.1」を上回る場合もあったという。
