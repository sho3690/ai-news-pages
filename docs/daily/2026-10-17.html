今朝のブリーフィング

今朝の紙面は、AIが「作る」話と「確かめる」話が同じ机に並んだ。Black Forest Labsは56億パラメータの画像生成モデルを、8GBのVRAMで動くINT8版まで添えて公開し、OpenAIはChatGPTの音声を日本語を含む13の新しい声で更新した。Reflectionは料金の安さではなく、少ないトークンで仕事を終えることを売りにしている。

一方Anthropicは、Claude Code自身のコードの約9割をClaudeが書いていると明かし、読む作業の大半を機械に移しつつ、失敗を素早く取り消せる仕組みに投資したと説く。GitHubもAIによるプルリクエスト走査を一般提供した。書く速度が増すほど、検める力が価値を持つ。生成の次の競争は、確認の上手さかもしれない。

01

FLUX 3 Image Klein登場　8GBのGPUで動く4K対応の画像生成

Black Forest Labsが5.6Bパラメータのオープンウェイト画像生成モデルを公開した。4K出力や最大10枚の参照画像、範囲指定の編集に対応し、INT8版は8GBのVRAMで動く。

「FLUX 3 Image Klein was also optimized for consumer GPUs.」— Black Forest Labs

Black Forest Labs（10/15）

02

ChatGPTの音声が進化　GPT-Live-1.1で日本語など13の新ボイス

OpenAIがChatGPT、Codex、dots向けの音声モデルGPT-Live-1.1を展開開始。日本語を含む多言語の発音が改善され、開発者は説明文や録音からカスタム音声も作れる。

「GPT-Live-1.1 is an update for ChatGPT, Codex, and dots, introducing 13 new voices」— OpenAI Developer Community

OpenAI Developer Community（10/15）

03

Reflectionがオープンモデル「Beam」の重みを公開　勝負は安さより少ないトークン

総501B・稼働23BのMoEモデルをApache 2.0で公開した。Terminal-Bench 2.1で約80.1%を記録し、不要なトークンを減らす強化学習で1タスクあたりの消費を抑えたという。

「You don't give up anything. You just penalize it in terms of how many tokens it can use.」— VentureBeat

VentureBeat（10/16）

04

Anthropicのコードレビュー術　PRは倍増、取り消しは4割減

Anthropicが社内のレビュー体制を公開した。6〜9月にマージされたPRは2倍超になり、取り消し率は40%以上低下。リスクに応じて人の承認を変える多層構造だという。

「We didn't remove review. But we did move most of the reading to machines, optimized for human time and attention, and invested heavily in making it fast and easy to undo mistakes.」— claude.dev

claude.dev（10/15）

05

GitHubの「AI Scan」が一般提供　CodeQL未対応の言語もPRで走査

PHPやShell、Terraform、DockerfileなどCodeQLが扱えない言語を、AIがプルリクエスト上で走査する機能。指摘には「AI」ラベルが付き、自動修正案も出るが、マージは止めない。

「AI Scan for pull requests is now generally available.」— GitHub Changelog

GitHub Changelog（10/15）
