今朝のブリーフィング

きょう集まった話題に共通するのは、当たり前だと思っていた境界が静かに溶けていく感触だ。Runwayの「Solaris」はアプリの画面をコードではなく動画として生成し、Perplexityはタスクをクラウドと手元のMacの間で自在に行き来させる。Metaのコーディングエージェントも、一つの知能から複数のサブエージェントを操る指揮官へと役割を変えた。

そんな中、Anthropicは新型番「Claude Fable 5.1」を、目立った発表もないままリリースノートにひっそり書き加えた。利用上限の計算方法を見直したClaude CodeやGemini Notebookの動きも合わせると、派手な新製品競争の裏側で、AIの土台そのものが日々静かに組み替えられている一日だったと言える。

01

Claude最新版「5.1」、発表なき投入

Anthropicが、最上位モデル「Claude Fable 5」の後継となる「Claude Fable 5.1」と、限定公開の「Claude Mythos 5.1」を投入。ブログでの大々的な発表はなく、リリースノートへの追記という静かな形での投入だった。

「We've launched Claude Fable 5.1, the successor to Claude Fable 5 for long-running agentic coding, knowledge work, and research, alongside Claude Mythos 5.1 for Project Glasswing participants.」— Anthropic

Claude Platform Docs（9/1）

02

コード不要、"見て動くアプリ"爆誕

Runwayが、動画モデルを土台にアプリ画面そのものをリアルタイム生成する「インターフェース・ワールドモデル」第1弾「Solaris」を発表。コードを介さず、ユーザーの操作に応じて1フレームずつ画面を描き直す。

「Solaris instead renders that layer directly.」— Runway

Runway（8/31）

03

Metaのコーディング相棒、「見習い」卒業

Metaのターミナル型コーディングエージェント「Muse Code」がベータを終了し正式版に。複数のサブエージェントで作業を並行処理する「ワークフロー」機能や、TypeScript SDKのプレビューも新たに加わった。

「Muse Code is now out of beta with the following new features and additions」— Meta

Meta（8/31）

04

Claude Codeの上限25%増、実は"目減り"

Anthropicが「Claude Code」の週次利用上限を9月14日から恒久的に25%引き上げると発表。ただし現在実施中の期間限定プロモーション（50%増）と比べると、実質的には目減りとなる。

「引き上げ前の上限を100とすれば、プロモーション中の上限は150、9月14日以降は125となるため、プロモーション上限からは約17％減（150→125）となる」— 窓の杜

窓の杜（9/1）

05

Perplexity、機密データは"手元で処理"

Perplexityが、Mac版アプリに処理をクラウドと端末で分担する「ハイブリッドコンピュート」機能を追加。個人情報を含む機密性の高い作業は、クラウドから手元のローカルモデルへ引き継がれる。

「Computer now splits a task between cloud models and a local model on your Mac,」— 9to5Mac

9to5Mac（9/1）

06

Gemini Notebook、上限が5時間ごとリセットに

Googleが「Gemini Notebook」の利用上限の仕組みを刷新。9月2日から、これまでの1日ごとのリセットをやめ、処理の重さに応じて5時間ごとに上限が回復する柔軟な方式に切り替える。

「リセットは5時間ごと：これまでの1日ごとから改められ、1日を通して作業を続けやすくなる。」— 窓の杜

窓の杜（9/1）

07

Google、"未来予知AI"に新版投入

Google Researchが、時系列予測AI「TimesFM-3」を公開。売上や客足、天気など複数の変化するデータをまとめて読み込み、追加学習なしで将来の数値を予測できる。

「TimesFM-3は売上や客足、天気など時間とともに変化する複数のデータをまとめて読み込み、将来の数値を予測できるAIです。」— GIGAZINE

GIGAZINE（9/1）

08

AI秘書、放置しても"時間になれば"実行

学習しながら成長するAIエージェント「Hermes Agent」に、日時や間隔を指定してタスクを自動実行する「Cron」機能が搭載された。デスクトップアプリを起動していなくてもバックグラウンドでジョブが走る。

「PCを稼働させ、Windowsにログインした状態を維持する必要があるものの、Hermes Agentのデスクトップアプリを起動し忘れてジョブが実行されない事態は避けられそうです。」— GIGAZINE

GIGAZINE（9/1）
