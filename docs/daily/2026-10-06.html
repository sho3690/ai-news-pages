今朝のブリーフィング

今朝の発表を並べてみると、どれも「誰のものか」という問いに行き着く。米国の新興企業Reflection AIは、5010億パラメータの重みを公開する前提のオープンモデルBeamを披露し、ドイツのAleph Alphaは自国で育てた780億パラメータのKolibriをApache 2.0で世に出した。大きなモデルを一部の巨大企業の外に置こうとする動きである。

一方でOpenAIは、生成した文章に見えない透かしを入れる仕組みを用意し、GitHubはAIのコードレビューを測る物差しを公開した。作る側の競争が一巡すると、出来を測り、出どころを示す道具が要る。つくる力と確かめる力が揃って、AIは初めて社会の道具になるのだろう。

01

Reflection AIが初の大型オープンモデル「Beam」、中国勢に比肩を主張

Reflection AIが5010億パラメータ（アクティブ230億）のオープンウェイトモデルBeamを発表した。Z.aiのGLM-5.2並みの性能を推論計算量3〜4分の1で出すとうたうが、独立した検証はまだで、重みの公開は今月中の予定。

TechCrunch（10/5）

02

独Aleph Alphaが「Kolibri」公開、ドイツ語に強い780億パラメータ

Aleph Alphaが、MoE構成で総780億・アクティブ約30億パラメータのKolibriをApache 2.0で公開した。事前学習データの約23%がドイツ語で、エージェント処理やツール呼び出しにも対応する。

Aleph Alpha（10/5）

03

Cohere、エージェント基盤「North 2」発表　記憶機能とコスト管理を強化

Cohereが企業向けAIエージェント基盤North 2を発表した。再利用できるエージェントの作成や自然言語でのアプリ作成、スキル・ライブラリ・記憶機能、トークン消費の上限管理などを備える。

「North 2 is Cohere's biggest upgrade yet — unifying enterprise‑grade security, intelligence, cost governance, and full‑stack control into a single agentic AI platform that runs wherever your data lives.」— Cohere

Cohere（10/5）

04

ChatGPTの文章に「見えない透かし」、APIでも選択可能に

OpenAIが、ChatGPTやCodexの生成テキストに、単語選択を微調整する透かし技術「textGrain」を導入する。EUの規則に対応するもので、APIでも一部モデルで任意に有効化できる。

「[Watermarks] can indicate that an OpenAI system generated or processed part of a passage, but not how much human judgment, editing, or creativity went into it」— TechCrunch

TechCrunch（10/5）

05

GitHub、AIコードレビュー役の腕比べ「ReviewBench」を公開

GitHubが、AIコードレビューエージェントを測るオープンなベンチマークを公開した。実在のプルリクエスト219件を使い、重大度やカテゴリ別に精度を比べられる。

「We analyzed 103.9 million GitHub pull requests to characterize the real-world distribution of code review workloads.」— GitHub Blog

GitHub Blog（10/5）
