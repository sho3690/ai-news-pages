今朝のブリーフィング

Metaが初の最前線モデル「Muse Wonder」を世に出した。TechCrunchによれば、同社の評価ではFable 5.1やGPT-6 Astraに並ぶ得点だという。一方、ClaudeではOpus 5.5への依頼が未発表のモデルに振り分けられているらしく、Anthropicの担当者は「最良はこれから」と投稿した。Googleの画像モデルにも、Nano Banana 3 Proとみられる名前が見つかった。

発表された新顔と、まだ名前だけの新顔が同じ朝に並ぶのが、いまのモデル競争の風景である。ただし後者は兆候にすぎず、公開の約束はどこにもない。看板が掛かるまで、期待は半分に聞いておくのがよい。

01

Meta、初の最前線モデル「Muse Wonder」を投入　最上位は「Full」

MetaがMuse WonderとMuse Wonder Fullの2モデルを公開した。Wonderは100万トークンあたり入力4ドル・出力20ドルのAPIで使え、FullはMuse Code契約者に限られる。性能はMeta自身の評価でFable 5.1やGPT-6 Astraに並ぶという。

「Wonder Full will only be available to Muse Code subscribers and will not be served through the API.」— TechCrunch

TechCrunch（10/12）

「Anthropic appears to be quietly testing another model in the wild.」— TestingCatalog
