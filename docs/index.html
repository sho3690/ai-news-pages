週明けの朝、二つの「作り方」の話が並んだ。AnthropicのClaude Fable 5.2は、拡散モデルで絵を生むのではなく、コードで筆致を重ねて描く。駐車場の風景には約70万のストロークを費やし、失敗は上から塗り直すという。一方、美団（Meituan）のLongCat-2.5は、1.6兆パラメータのエージェント向けモデルで、重みがMITライセンスで公開され、Nvidia GPUを使わずに育てられたと伝えられる。

画像を「生成する」のか、「描く」のか。賢さを借りるのか、手元に置くのか。結果だけでなく、そこへ至る道筋まで競い合う時代になったようだ。道具の選択肢が広がるほど、問われるのは何を作らせるかである。
