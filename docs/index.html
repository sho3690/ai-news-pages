今朝のブリーフィング

今朝の話題に共通するのは、AIが「人の手を借りずに動く」ための足場づくりだ。Anthropicは、役割ごとに分けた複数のサブエージェントを、新しいモデルなら一つにまとめたほうが速いこともあると説いた。分業を前提にした設計が、モデルの成長で見直される時期に入ったらしい。

GoogleはAI Studioに、エージェントの設定や実行履歴を管理する画面を用意しているという。スマートフォンを操る公開モデルのOpenMobile-2は、学習データの量より、触れたアプリの種類の多さが効くと報告した。Metaのアシスタントでは、アバターを共有する機能が準備されている。いずれも発表前の兆しや研究段階の話で、完成形はまだ見えない。ただ、道具立てが整うほど、問われるのは任せ方の上手さになる。

01

Anthropic「サブエージェントは束ねたほうが速い」　1体化を推奨

新しいモデルは調整役の多くを自力でこなせるとして、複数のサブエージェントを、必要な文脈だけ呼び出す1体のエージェントに統合する検討を促した。ある比較では約2倍速く、GitHubで移行キットも公開する。

「Anthropic says sub-agents still make sense when a single agent's context window shows measurable performance degradation」— THE DECODER

THE DECODER（10/25）

02

スマホ操作AI「OpenMobile-2」公開　アプリの種類が成績を左右

南京大学やSenseTimeなどの研究者らが、9Bと27Bのオープンなスマホ操作エージェントを公開。110超のアプリを使った練習環境で学習し、実機テストSPA-Benchでオープンモデル最高の成績を出した。

「More data alone doesn't make smartphone agents better.」— THE DECODER

THE DECODER（10/25）

03

Google AI Studioに「Managed Agents」専用画面の準備か

開発者がエージェントの設定、環境や認証情報の管理、トリガーの定義、過去の実行の確認をできる画面を準備中と報じられた。公開時期は未発表。

「Google has not confirmed a rollout date for the interface.」— TestingCatalog

TestingCatalog（10/25）

04

MetaのMuse、アバターの共有機能を準備中

Web版Museに、動くアバターをプレビュー画面から共有リンクやコピー用URLで渡せる機能が見つかった。まだ一般には公開されておらず、時期も未定。

「The sharing interface has surfaced in Muse's web implementation, but it is not publicly available yet.」— TestingCatalog

TestingCatalog（10/25）
