今朝のブリーフィング

チャットの顔が、また一段と磨かれた朝だ。OpenAIはChatGPTの会話用GPT-6.2を更新し、推論や画像理解、ウェブ検索の精度向上をうたった。Googleは上位モデルGemini 4 CarbonをAntigravityの有料Proに広げ、検索のAIモードも、DriveやWalletの情報を踏まえて答えられるようになった。AIが「自分のことをよく知る相手」へ近づいていく。

コードの現場では、AnthropicがPRの審査から修正、承認までを担うClaude Shipを投入した。Z.aiは、層を二度通す新構造のGLM-5.4を発表している。賢さの競争は、大きさだけでなく仕組みの工夫へ広がる。さて、任せる範囲をどこで線引きするか。

01

ChatGPTの会話用GPT-6.2が更新　推論・画像・検索が向上と発表

OpenAIがChatGPTのPlus・Pro・Business・Enterprise向けに、チャット用GPT-6.2を展開。GPT-6より推論、画像理解、ウェブ検索が良くなったとする。WorkとCodex向けモデルは変わらない。

「These numbers only apply to ChatGPT's chat mode.」— THE DECODER

THE DECODER（11/23）

02

ChatGPTの常時稼働エージェント「Dots」、EUにも到着

日常会話向けに調整したGPT-6.2 SolがChatGPTのChatタブに登場。初回ローンチで対象外だったEUにもDotsが広がり、旅行モードや刷新されたUIも確認されている。

「Dots are OpenAI's always-on agents inside ChatGPT.」— TestingCatalog

TestingCatalog（11/24）

03

Anthropic「Claude Ship」登場　PRの審査・修正・承認までAIに

TeamとEnterprise向けにベータ提供。自動のPRレビュー、修正と確認、ポリシーに基づく承認をまとめて担い、Claude Codeの「/ship」コマンドから始められる。

「Anthropic built Claude Ship around its own Claude Code team, where Claude writes most of the code.」— TestingCatalog

TestingCatalog（11/23）

04

Antigravityに「Carbon」が降臨　$19.99のProでも使える

GoogleのAntigravityで、Gemini 4 Carbonが有料Proに開放され、全員のクォータもリセット。計画役と実行役のモデルを選ぶパネルや、長時間タスク用のライブチェックリストも加わった。

「Google is dropping the separate Argon quota bucket for paid Pro users.」— TestingCatalog

TestingCatalog（11/24）

05

GLM-5.4は「同じ層を二度通す」　Z.aiの初のループ型Transformer

Z.aiの7500億パラメータ級モデルが、28層を2回走らせて深さを稼ぐ構造に。2〜3兆級に匹敵と主張するが、ベンチマークは30Bの試験版によるもので、重みの公開は安全性確認の後という。

「Z.ai is moving its flagship model to a loop architecture that runs some of its layers twice.」— THE DECODER

THE DECODER（11/23）

06

検索のAIモードがDriveとWalletにつながる　答えが「自分仕様」に

Googleが検索のAIモードのPersonal Intelligenceを拡張し、Google DriveやGoogle Wallet、Geminiアプリの会話も参照できるように。接続は利用者が選べ、いつでも解除できる。

「The feature can already connect to apps like Gmail, Google Calendar, and Google Photos.」— TechCrunch
