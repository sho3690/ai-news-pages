今朝のブリーフィング

今朝の話題には、AIの「出力」をめぐる線引きという共通点がある。Anthropicは、Claude Codeに既存ゲームの複製を断らせ、旧モデルの文章にも見えない透かしを入れ始めた。作れることと、作ってよいことの間に、作り手自身が線を引き直している。

一方でOpenAIは、GPT-6 Astraに装置の設計を丸ごと任せ、一週間足らずで仕上げたと語った。ただ、製造上の細部は見落としたという。Anthropicの新機能Message Threadsは、長い会話のたびに全履歴を送り直す手間を省く。力を伸ばすことと、その使い方を整えることは、いま同じ速さで進んでいる。

01

Anthropic「Message Threads」公開　長い会話の初回トークンが35%速く

AnthropicがAPIの新機能をパブリックベータで公開した。毎回会話全体を送り直さず、差分だけを送る方式で、50万〜100万トークン級の依頼では最初のトークンまでの時間が約35%縮む。

「Token usage doesn't change since Claude still reads the full conversation history.」— THE DECODER

「Anthropic is blocking its coding assistant Claude Code from recreating existing video games.」— THE DECODER

03

GPT-6 Astraが装置を一から設計　OpenAI「1週間足らず」

「Astra didn't always account for manufacturing constraints, tolerances, and assembly details.」— THE DECODER

04
